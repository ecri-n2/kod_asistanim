# Projenin Adı: Kod-Asistan v0.1
## Projenin amacı: Kullanıcıların günlük işlerinde (hesaplama, selamlama vb.) yardımcı olacak bir dijital asistan tasarlamak
## Projenin Hedefleri: Bu asistanın ilerleyen zamanlarda hamgi özellikleri kazanacağı maddeler halinde yazılacak (örneğin v1.0 Akıllı Menü, v2.0 Veri Saklama)
## Projenin Kapsamı: Kullanıcıdan adını soyadını alıp birleştiren ve selamlama yapan basit bir asistan akışı
